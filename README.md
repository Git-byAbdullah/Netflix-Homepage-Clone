# 🎬 Netflix Homepage Clone

A responsive **Netflix homepage clone** built with HTML5, CSS3, and JavaScript. The project recreates the visual structure of a Netflix-style streaming homepage while practicing modern frontend development and responsive web design.

## ✨ Features

* 🎬 Netflix-inspired homepage design
* 📱 Responsive layout for different screen sizes
* 🔥 Trending Now section
* 🖼️ Movie and TV show posters
* 🔢 Dynamic trending titles using JavaScript
* 🎨 Netflix-inspired styling and layout
* 🔐 Sign-in interface
* 📺 Content and promotional sections
* 🔗 Interactive frontend elements

## 🛠️ Technologies

* **HTML5**
* **CSS3**
* **JavaScript**
* **Responsive Web Design**
* **Font Awesome**

## 📱 Responsive Design

The website is designed to adapt to different screen sizes, including desktop and mobile devices.

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/Git-byAbdullah/Netflix-Homepage-Clone.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

For local development, you can also use the **Live Server** extension in VS Code.
